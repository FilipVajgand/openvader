The first release of OpenVader, a native macOS app for configuring the Flydigi Vader 5 Pro without Windows or Space Station. Settings are saved on the controller, so they keep working everywhere afterwards: other Macs, a PC, a phone, a Switch, and over Bluetooth.

## Download

- **OpenVader-0.1.0.zip**: the app, for Apple silicon and Intel Macs on macOS 14 or newer.
- **vaderctl-0.1.0.zip**: the same features as a command-line tool.
- **SHA256SUMS.txt**: checksums.

## First launch

OpenVader is not notarized by Apple, so macOS blocks it the first time. Unzip it, move it to Applications and open it once. Then go to **System Settings → Privacy & Security** and click **Open Anyway**. Or run:

```sh
xattr -dr com.apple.quarantine /Applications/OpenVader.app
```

Set the switch on the back of the controller to the USB-stick position, connect the 2.4 GHz receiver or a USB-C cable, and switch the controller on. If macOS asks whether to allow the accessory, allow it.

## What you can do

- Remap every button, including M1–M4, C, Z, LM and RM, with turbo.
- Sticks: dead zones, response curve and circularity.
- Triggers: travel window, for a hair trigger.
- Gyro: aim with a stick (runs on the controller itself) or move the Mac's pointer.
- Vibration: grip and trigger motors.
- Lighting: ten effects including strobe, rainbow fade, comet, scanner and fire, with colours, brightness and speed.
- Macros, stored and played by the controller.
- Keyboard and mouse actions on the Mac for buttons, sticks and gyro. These need Accessibility access, which macOS asks for again for each new version.
- Four on-board profiles, a profile library, backups with exact restore, a live input test, and a firmware check that never flashes anything.

## Tested

On a Vader 5 Pro with firmware 7.1.5.0, on macOS 26. The README's status table lists what was checked on hardware and what was not yet.

## Known limits

- Settings can be changed over the receiver or a cable only. Bluetooth works for playing but has no settings channel.
- Flydigi's web app installs firmware 7.2.x, which uses a different settings protocol. OpenVader has not been tested with it, so stay on 7.1.x for now. The desktop Space Station on Windows offers 7.1.5.4.
- Over Bluetooth, rumble that games send to the trigger motors does not reach them (a controller firmware limit); grip rumble works.
